# Overviews — Daily New-Subscriber Input (SOP)

**Goal:** Once per day, record each creator's **new subscribers from the previous day** into the MAHO tracking app, so subscriber growth is tracked daily.

**Frequency:** Once per day (you log *yesterday's* numbers).

**Logins you need:**
- Infloww (the OnlyFans management tool)
- MAHO tracking app — `https://linkme-app.vercel.app/admin`, account `overviews@maho-management.com`
  - First time only: enter that email + choose a password on the login screen — that becomes the account's password.

---

## Part A — Read the numbers from Infloww
1. Log in to **Infloww**.
2. For **each creator**, open that creator's **Statistics** page.
3. Set the date to **yesterday** (the full, completed day).
4. Read the **"New subscribers"** number for that day.
   - ✅ Use **New subscribers** only. This is what we track (it includes both free and paid new subs).
   - ❌ Do **NOT** include **"Recurring subscribers"** — those are renewals/rebills, not new subscribers.
5. Write down that creator's number.
6. Repeat for **every** creator. Some models have more than one account (e.g. a main + an ESP/2nd account) — note each one separately.

## Part B — Enter the numbers in the MAHO app
1. Go to **`https://linkme-app.vercel.app/admin`** and log in as `overviews@maho-management.com`.
2. In the left sidebar, click **Conversions**.
3. Open the **"Daily Input"** tab.
4. The date should already be set to **yesterday** — double-check it's the correct date before typing.
5. For each creator, type that creator's **New Subs** number (from Infloww) into the **"New Subs"** field. (Use the search box at the top to jump to a creator fast.)
6. Click **Save**.
7. Done — yesterday's numbers are now recorded.

---

## Rules
- Always use **yesterday's** date (a fully completed day) — never today.
- **New subscribers only** — never include recurring.
- If a creator had **0** new subs, enter **0** (don't leave it blank — a real 0-day matters for the streak tracking).
- Enter every account, including secondary/ESP accounts, separately.
- If a number looks way off, re-check: right date? Read "New", not "Recurring"?

**Time:** ~5–10 minutes a day once you're used to it. Best done each morning for the day before.
